# User guide

CloudScope Web is the browser viewer for CloudScope analysis datasets saved as OME-Zarr. Nothing needs to be installed to view a published dataset.

[Open CloudScope Web](https://mapmanager.github.io/cloudscope-web/){ .md-button .md-button--primary }

A typical viewing session is simple:

1. Open CloudScope Web in a browser.
2. Open one of the provided samples or paste the URL of a published CloudScope dataset.
3. Select an image from the collection.
4. Use the image controls to inspect channels, ROIs, metadata, and analyses available for that image.
5. Copy the CloudScope Web URL when you want to share the current dataset and primary selection with a colleague.

Continue with [Using CloudScope Web](using-cloudscope-web.md) for the main walkthrough, or go directly to [Sharing a view](sharing.md).
